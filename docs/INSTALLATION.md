# Installation Guide

This repository is designed to be copied directly into a GitHub profile repository named after your account, such as MichaelAcostaDev.

## Steps

1. Create a repository with the same name as your GitHub username.
2. Copy the contents of this folder into the new repository.
3. Commit and push the files to GitHub.
4. Open the repository on GitHub and enable GitHub Actions.
5. Wait for the snake workflow to generate the contribution animation.

## Required files

- README.md
- assets/
- .github/workflows/
- docs/

## Notes

The README uses public widgets and static assets, so no additional build step is required.
