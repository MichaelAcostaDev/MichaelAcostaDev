# Setup Guide

## Enable GitHub Actions

1. Open your repository on GitHub.
2. Navigate to Settings > Actions > General.
3. Choose the option to allow all actions and reusable workflows.

## Enable the Snake Animation

1. Ensure the workflow file .github/workflows/snake.yml is present.
2. Open the Actions tab.
3. Run the workflow manually once.
4. The generated SVG will be published to the output branch and referenced by the README.
